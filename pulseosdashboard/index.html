Made for a private workflow

PulseOS Dashboard is developed and operated by Kuno Boers, the independent developer behind PulseOS in the Netherlands. The macOS app is currently used privately for the developer’s own planning and authorized social accounts. It is not open for public registration or download.

This website explains the app and its policies. It does not display the private dashboard, account statistics, tasks or credentials.

How the TikTok connection works

The integration is being tested in a TikTok developer sandbox. An authorized access token lets the app retrieve the connected account’s identity, follower count and public-video details and engagement metrics through TikTok’s official API.

  • user.info.basic — identify the connected account.
  • user.info.stats — read account statistics, currently the follower count.
  • video.list — read public videos and supported engagement metrics.

These permissions provide read access. The integration does not publish videos, edit posts, delete content or read private messages.

The current app supports manual configuration of an authorized token. An integrated TikTok sign-in flow is still in development. Access depends on TikTok authorization and sandbox account eligibility.

Your data, with clear controls

Dashboard records are stored locally. Optional exports or synchronization through a folder you choose can create additional copies. TikTok tokens are stored in the Mac’s Keychain. Removing a local connection stops its use in Dashboard; previously imported reports are retained until deleted separately.
